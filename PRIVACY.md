# Privacy Policy for Subtitle Studio Pro

Last updated: September 18, 2026

## 1. Overview

Subtitle Studio Pro is an internal desktop application used by authorized staff for YouTube channel operations, multilingual subtitle management, and localized video metadata management.

The application is used to manage authorized YouTube content on behalf of content partners, including DramaBox.

Subtitle Studio Pro uses YouTube API Services and Google OAuth to perform authorized content-management operations.

## 2. Information We Access

When an authorized user connects a Google/YouTube account, Subtitle Studio Pro may access information necessary to provide its content-management functions, including:

- YouTube channel information
- Video IDs and basic video metadata
- Existing caption and subtitle tracks
- Localized video titles and descriptions
- Information required to upload or update captions
- OAuth authorization tokens required to access authorized YouTube channels

The application does not request or store users' Google or YouTube passwords.

## 3. How We Use YouTube API Data

YouTube API data is used only for authorized YouTube channel management purposes, including:

- Uploading and updating multilingual subtitles
- Checking existing caption tracks
- Managing localized video titles and descriptions
- Verifying video and channel information before publishing
- Reducing repetitive manual operations in YouTube Studio
- Supporting multilingual publishing workflows for authorized content

Subtitle Studio Pro does not use YouTube API Services to generate artificial views, likes, subscriptions, comments, or other forms of engagement manipulation.

## 4. Google OAuth and Authorization

Users authorize access to their Google/YouTube accounts through Google's OAuth authorization process.

OAuth access is initiated by the account owner or an authorized channel operator.

Authorization tokens may be stored locally on the authorized user's device so that the application can maintain authorized access without requiring the user to sign in again for every operation.

Users can revoke the application's access to their Google Account at any time through their Google Account security settings.

## 5. Data Storage and Security

Subtitle Studio Pro only stores information necessary for authorized content-management operations.

Where applicable, configuration files, authorization tokens, task information, and operational records are stored locally on the authorized operator's device.

We take reasonable technical and organizational measures to protect YouTube API data and authorization information from unauthorized access, disclosure, or misuse.

## 6. Data Sharing

We do not sell YouTube API data or Google user data.

We do not use YouTube API data for advertising profiles, unrelated marketing purposes, or unauthorized analytics.

Authorized data is only used by authorized staff and service providers as necessary to operate the YouTube channels and content for which access has been granted.

## 7. Data Retention and Deletion

We retain data only for as long as necessary to provide the application's authorized content-management functions.

Users may:

- Revoke Google OAuth authorization at any time
- Delete locally stored authorization tokens
- Request deletion of user-related data associated with the application

For data deletion or privacy requests, please contact us using the contact information listed below.
