# Subtitle Studio Pro

Subtitle Studio Pro is an internal desktop application used by authorized staff for YouTube channel operations and multilingual content management.

The application is used to manage authorized YouTube content on behalf of content partners, including DramaBox.

Main functions include:

- Uploading and updating multilingual subtitles
- Managing localized video titles and descriptions
- Checking existing caption tracks
- Managing authorized YouTube channels through Google OAuth
- Improving the efficiency of multilingual publishing workflows

This application is intended for internal operational use only. It is not used to generate artificial views, likes, subscriptions, comments, or other forms of engagement manipulation.
